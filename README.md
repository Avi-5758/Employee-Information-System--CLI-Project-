# Employee Information System (CLI)
A simple, interactive Command-Line Interface (CLI) application built in Python for managing employee records using Python's object serialization (`pickle`) module.
************************************************************************************************************************************
## 🚀 Features
* **Add Employee**: Register new employee details (Employee ID, Name, Salary).
* **View Employees**: Display all stored employee records or search for a single employee by ID.
* **Update Salary**: Modify and update the salary of an existing employee.
* **Delete Record**: Remove an employee record from the system.
* **Binary File Persistence**: Automatically saves and loads records using a `.data` file with `pickle`.
